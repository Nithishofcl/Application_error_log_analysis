# Application Error Log Analysis

## Project Objective
To analyze application logs using Linux commands and identify errors for basic application support troubleshooting.

## Tools Used
- Linux / Ubuntu
- grep
- cat
- tail

## Issues Identified
1. Database connection failed.
2. HTTP 500 Internal Server Error.
3. Response time exceeded threshold.

## Troubleshooting Steps
1. Used cat to view the application log.
2. Used grep to identify ERROR messages.
3. Used tail to check the latest log entries.
4. Recommended checking database connectivity, application logs, and server health.

## Outcome
Identified application errors and documented initial troubleshooting steps for L1 support.
