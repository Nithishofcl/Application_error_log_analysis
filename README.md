# Application_error_log_analysis

A beginner-level Application Support project demonstrating how Linux commands can be used to inspect application logs, identify errors, and document troubleshooting steps.

## Skills Demonstrated
- Linux command-line basics
- Log analysis
- Error identification
- Incident documentation
- L1 application support troubleshooting

## Commands Used
- cat application.log
- grep "ERROR" application.log
- tail application.log

## Project Files
- application.log
- incident_report.md
